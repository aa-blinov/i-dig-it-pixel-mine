# Ресёрч

Ступень 2 лестницы разработки: прежде чем решать задачу, выясняем, решалась ли она раньше. Решалась — берём подход сообщества. Нет — ищем похожую. Каждое исследование записывается сюда, чтобы следующий агент или человек не повторял поиск.

## Формат заметки

```markdown
# <Вопрос>

**Ступень:** какой задаче нужен ответ · **Решение:** одной строкой

## Решалась ли раньше
## Варианты
| Вариант | За | Против |
## Решение и почему
## Источники
```
