# Игровой пиксельный шрифт с полной кириллицей

**Ступень:** интерфейс · **Решение:** Press Start 2P для заголовков и цифр, Handjet для текста

## Решалась ли раньше

Да, но в основном для латиницы: большинство пиксельных шрифтов Google Fonts кириллицы не имеет. Проверка шла скриптом: есть ли в шрифте все 66 букв русского алфавита.

## Варианты

| Шрифт | Кириллица | Почему не подошёл или подошёл |
| --- | --- | --- |
| Tiny5 + Ark Pixel | есть | Первая версия; игрок назвал шрифт «очень типовым» |
| Pixelify Sans | есть | «д» похожа на «а», у «К» лишний штрих: русский текст читается с трудом |
| VT323 | нет | Не подходит |
| Silkscreen, Jersey 10, Micro 5, Bytesized, Sixtyfour | нет | Не подходят |
| DotGothic16 | есть | Моноширинный и широкий, абзацы на телефоне не помещаются |
| Press Start 2P | есть | Узнаваемый аркадный, чёткий; для абзацев слишком широкий |
| Handjet | есть | Узкий, с пиксельным характером, хорошо читается в абзацах |

## Решение и почему

Пара из двух шрифтов: Press Start 2P (заголовки, кнопки, цифры) даёт игре аркадный голос, Handjet (текст) читается в абзацах. Press Start 2P уменьшен через `size-adjust: 62%`, Handjet увеличен до 125%, чтобы кегли из макета остались прежними. Оба урезаны до латиницы и кириллицы (около 50–80 КБ).

Ловушка: у Handjet есть ось формы элементов; при значении 0 буквы рисуются пустыми. Использовать значение по умолчанию.
