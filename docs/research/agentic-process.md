# Какие готовые инструменты взять для процесса агента

**Ступень:** рабочий процесс · **Решение:** Spec Kit, AGENTS.md, Impeccable, Humanizer-ru, симуляция персон

## Решалась ли раньше

Да, и много раз. Для каждой части процесса нашёлся готовый инструмент сообщества, своими руками собраны только проверки, которые нужны именно этой игре: эталонный прогон, проверка пакета Construct, страница проверки.

## Варианты и выбор

| Часть процесса | Готовое | Взяли | Зачем |
| --- | --- | --- | --- |
| Спецификации и план | Spec Kit от GitHub | да | Конституция проекта и цепочка «спецификация → план → задачи → реализация» |
| Правила для агента | AGENTS.md, открытый формат | да | Один файл, который читает любой агент |
| Связь с движком | MCP-сервер Construct 3 | да | Спрайты, проверка проекта, сборка пакета без ручной работы в редакторе |
| Проверка интерфейса | Impeccable | да | Детектор проблем вёрстки и контраста по живой странице |
| Тексты на русском | Humanizer-ru | да | Вычитка без нейросетевых оборотов |
| Проверка на игроках | Живой тест | план в `docs/qa/playtest-plan.md` | Проводит человек |
| Проверка на игроках до людей | Симуляция персон субагентами | да | Пять игроков разного возраста и опыта, правило «чиним, если назвали двое» |
| Поведение игры при рефакторинге | Golden master | сделали сами | `tests/golden.mjs`, десять партий кадр за кадром |

## Решение и почему

Готовое берём там, где задача общая (спецификации, правила, вёрстка, тексты). Своё пишем там, где проверка специфична для игры и движка. Каждый инструмент оформлен скиллом с петлёй и условием выхода: см. `.claude/skills/`.
