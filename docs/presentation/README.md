# Лекция «Агентная разработка»

Лекция для геймдева о том, как этот репозиторий сделан с агентом. Здесь лежат оригиналы, из которых собираются слайды, и сценарий выступления.

| Файл | Что это |
| --- | --- |
| [lecture-deck.pdf](lecture-deck.pdf) | Слайды для показа, 21 страница |
| [lecture.md](lecture.md) | Документ лекции: сценарий по слайдам и разделы 1–8 с подробностями |
| `lecture-deck.html` | Те же слайды одной страницей, собираются скриптом |
| `project/deck.json`, `project/slides/` | Оригинал: порядок слайдов и по файлу на слайд, в формате редактора Slides |
| `assets/` | Скриншоты игры и руды, которые стоят на слайдах |
| `icons/` | Значки [Lucide](https://lucide.dev), лицензия ISC |
| `fonts/` | Шрифт заголовков Grandis Extended из дизайн-системы EORA. Не в git: положите файл сюда перед сборкой, без него заголовки наберутся запасным шрифтом |

Живые версии: [слайды](https://claude.ai/artifact/26SVoBAtDXZxnBhj8xJ5Wy) и [документ](https://claude.ai/artifact/DNBH5fvtkweD5tR9CXbf4t). Ссылки открываются только тем, с кем ими поделились.

## Сборка

```bash
node tools/build-presentation.mjs --pdf --check
```

Скрипт собирает `lecture-deck.html`, печатает его в `lecture-deck.pdf` через Chrome или Edge без окна и сверяет слайды со сценарием: у каждого слайда в `lecture.md` есть блок «### Слайд N. Название» с тем же номером и тем же заголовком. Если слайд добавили, убрали или переименовали, а сценарий не поправили, проверка падает и называет слайд.

## Как обновить

1. Правки слайдов делаются в редакторе Slides. Потом файлы `project/` скачиваются сюда заново.
2. Правки сценария делаются в документе. Потом он экспортируется в Markdown и заменяет `lecture.md`.
3. Запустить сборку с `--check` и закоммитить оригиналы вместе с PDF.
