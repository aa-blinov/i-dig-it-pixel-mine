# Тест на живых игроках: не пугается ли новичок

Нужно 3–5 человек, которые игру не видели. На каждого уходит около 15 минут.

## Подготовка

1. Откройте игру на телефоне игрока (Preview в Construct или собранная версия).
2. Начните с чистого профиля: в меню браузера очистите данные сайта или откройте приватную вкладку.
3. Ничего не объясняйте. Скажите только: «Это игра про шахту. Играй, как хочешь, и думай вслух».

## Что делает игрок

1. Читает вступление или пропускает его.
2. Проходит контракт 1.
3. Проходит контракт 2 и заходит на базу.
4. Строит первую постройку.

## Что отмечать (да или нет)

| Момент | Да | Нет |
| --- | --- | --- |
| Сделал первый ход сам, без вопроса «что делать» | | |
| Понял, что топливо кончается (сказал или посмотрел на датчик) | | |
| Нашёл «Сдать смену» после нормы | | |
| Окно итога не напугало: понял, что получил | | |
| Открыл вкладку «База» сам после контракта 2 | | |
| Построил постройку без подсказки | | |
| Открыл меню и вернулся в игру без ошибок | | |

Запишите дословно каждый вопрос игрока и каждое «ой», «а что это», «я что-то сломал».

## Три вопроса в конце

1. Что было непонятно или неприятно?
2. Что хотелось сделать, но не получилось?
3. Захотелось бы вернуться завтра? Почему?

## Как читать результат

- Если «нет» в одном и том же моменте у двух и больше игроков, это место надо переделать.
- Дословные вопросы и испуги отправьте мне, я исправлю экраны и обновлю ux-map.md.
