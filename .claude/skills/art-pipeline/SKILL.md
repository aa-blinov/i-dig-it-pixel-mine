# Арт-пайплайн

Цель: графика собрана из исходников одной цепочкой команд и чёткая на любом экране.

## Цикл

Из корня репозитория, по порядку (каждый шаг перезаписывает результат предыдущего, порядок важен):

```bash
powershell -File tools/build-stage1-art.ps1     # фон, панели, спрайты в assets/generated/pixel-mine
node tools/apply-stage1.mjs                     # кладёт их в проект через MCP Construct
node tools/fix-collision-polys.mjs              # чинит полигоны столкновений
py tools/upscale-art.py                         # пиксель-арт ×4, фоны ×2, без сглаживания
RESVG=<папка с @resvg/resvg-js> node tools/build-hd-ores.mjs   # руды 256 px из векторных наборов
node tools/ship-icons.mjs                       # иконки кабины и игровые шрифты в files/
```

Потом скилл `verify-build` и `mobile-check`.

## Правила

- Пиксель-арт увеличивается только в целое число раз без сглаживания; сглаживание включено в проекте (sampling trilinear).
- Руды одного слоя различаются цветом и значком в углу (круг, треугольник, квадрат, звезда, ромб, крест).
- Шрифты: Press Start 2P для заголовков и цифр, Handjet для текста, оба урезаны до латиницы и кириллицы.
- Новый ассет только CC0 или OFL, запись в `docs/art-bible/assets.md` с источником.

## Готово, когда

Все шаги прошли, аудит без ошибок, руды и интерфейс проверены на телефоне.

## Ловушки

- В `.ps1` не писать кириллицу: Windows PowerShell 5.1 читает файл в ANSI. Русский текст собирать из кодов символов.
- `assets/source/` не в git, кроме шрифтов и векторных руд: исходные паки скачиваются по ссылкам из `docs/art-bible/assets.md`.
