I Dig It: Pixel Mine — локальный просмотр

Собери три одинаковых материала. На базе используй Tab и Enter для выбора кнопок. В панели «Управление» есть доступное поле с названиями материалов. В шахте стрелки перемещают курсор, Enter выбирает, Escape снимает выбор, R возвращает на базу. M переключает звук.
